Copy everything below the line into Claude Code, run from the root of `lukaskourilcz/aifirst` with this folder available at `docs/audit-2026-09/`.

---

You are implementing the findings of a pre-launch design and copy audit of DNESKAi, a Czech daily AI publication (Next.js 15 App Router, React 19, server components, static generation; pages in `app/[lang]/`, UI in `components/`, copy in `lib/i18n/dictionaries.ts`, tokens in `app/globals.css`, content as MDX in `content/articles/`, board records in `public/data/board/`). The audit is in `docs/audit-2026-09/` — read `README.md`, then `AUDIT_FACTS.md`, then open the `report/*.dc.html` pages in a browser when you need to see a mockup. `report/11 Action List.dc.html` is the ordered list you are executing.

## Rules
1. Cutting and tightening only. Do not add features, pages, widgets, accounts, comments, personalisation or new components. Where the audit says "hide", the route keeps building and stays reachable by URL (with `robots: { index: false }` where noted); only the links to it go.
2. Provenance, uncertainty and corrections stay visible. Every change to them is to state them better, never to remove them.
3. Czech is the only published locale. Every string a reader can see must be Czech; English machine values (`primary`, `rss`, `operational`, board reasons, curator notes) are either mapped to Czech or not rendered. Keep the `en` dictionary key-for-key in sync (the `Dict` type enforces it) but do not spend effort on English wording.
4. Do not touch content in `content/articles/**` or `public/data/board/**`. Fix rendering, not files. Upstream writing rules go into `docs/` as notes for the BoardlessAI prompt, not into MDX.
5. Keep the visual system: paper canvas, hairlines, radius 0, the three typefaces, the tokens in `:root`. Prefer deleting CSS to adding it.
6. Work in the order below (P0, then P1, then P2). Commit per numbered item with the item number in the message, e.g. `audit P0-01: weekend shows last edition as lead`. Run `pnpm lint && pnpm typecheck && pnpm test && pnpm check:content && pnpm build` before each commit; update or delete tests that assert on removed UI (e.g. `e2e/smoke.spec.ts`, `lib/__tests__/*`) rather than skipping them. Add tests only where a rule is easy to assert (date formatter, label map, weekend logic).
7. When a finding conflicts with something you discover in the code, prefer the audit's intent (what the reader sees) and leave a short note in `docs/audit-2026-09/IMPLEMENTATION_NOTES.md`. Also record there anything you deliberately did not do and why.
8. Typography of Czech text rendered by the app (dictionary strings and post-processed delivered text): typographic quotes „ “, non-breaking space after one-letter prepositions and conjunctions (k, s, v, z, o, u, a, i) and between number and unit, en dash (–) in ranges and as the sentence dash, never an em dash with spaces, dates as `25. 9. 2026` or `25. září 2026`.
