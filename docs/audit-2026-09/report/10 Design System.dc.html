Design system

The token layer is small, semantic and disciplined (radius 0, one accent, three status colours, three typefaces). The drift is one level up: ~10 kicker treatments, 6 chip variants, 5 row components and 6 empty-state classes doing the same jobs, and a handful of literal font sizes outside the scale. Five system-level changes below would resolve roughly forty of the page findings.
