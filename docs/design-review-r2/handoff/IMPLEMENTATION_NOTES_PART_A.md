## Deliberately not done, or done differently

- **Section assignment uses the lead story's tag, not the precedence rule.** Applying Regulace → Bezpečnost → Modely → Vývoj → Firmy a trh across all tags put 16 of 32 August–September editions in Regulace, because every edition covers several stories and any mention of a law won. `sectionOf()` takes the first tag that maps to a section (the lead story's), treats „umělá inteligence“ and bare company names as generic, and falls back to Modely. It uses the precedence only when one tag maps to two sections. The spread since August is Bezpečnost 11, Firmy a trh 7, Modely 5, Vývoj 4, Regulace 3. Upstream will set `section` explicitly in Part B.
- **Part A labels on the article.** The prompt uses „Dále v dnešním vydání“ and „Další z dnešního vydání“ for the previous and next editions. On a one-article day those headings would be untrue, so they read „Předchozí vydání“ and „Další vydání“ until Part B.
- **Provenance dictionary keys kept.** `article.provenanceUnreviewed/Reviewed/SourcesOne/SourcesMany` stay because the print view and `llms.txt` still build the statement from them, as A-06 requires.
- **`brand.responsiblePerson`** is set to „tým DNESKAi“ rather than deleted, because About uses it.
- **No new client code beyond the masthead.** `StickyHeader` is the one new client component. It also marks the current section, reading the article's `data-section`, because the shared layout can't know an article's section. The mobile drawer is the former MobileNav reshaped (`MastheadMenu`), and search stays one palette opened by a window event, so ⌘K never opens two dialogs.
- **No „Krátce“ chip in the archive filter.** There is no Briefs page for it to open until Part B.
- **The ledger host check drops nothing today.** It drops a row whose host doesn't match its registered source, but on 13. 9. the problem was titles that didn't match their URLs while the hosts matched `source_id`. That fix belongs upstream (UPSTREAM_REQUIREMENTS §4).
- **Two regressions caught and fixed on the branch.** The A-09 cleanup regex cut the last selector off the `.label--section` accent rule, so section labels rendered as mono metadata in A-09 to A-11. A-12 repaired it, and `lib/__tests__/stylesheet.test.ts` now fails on that shape.
- **Remaining upstream content problems the design surfaces:** the 25. 9. hero's alt text describes a server room while the photo is a circuit board; the same Pexels motherboard photo leads several recent editions. Both are UPSTREAM_REQUIREMENTS §3 items.
